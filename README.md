# Compass Bot

家庭向けのお小遣い学習サポート Discord Bot です。

## プロダクト目的

Compass Bot は、子どもが自分のお小遣いを自主的に管理し、親と並走しながらお金の使い方を学ぶためのツールです。
単なる残高管理、親による監視、罰則運用を目的としません。

子どもが「何に使ったか」「なぜ使ったか」「使ってみて満足したか」を記録し、あとから振り返れることを重視します。
親はその記録を見て、必要なときだけ支援・相談・安全確認を行います。

### 設計原則

- 子どもの主体性を優先する。親の管理画面や通知は、子どもの自律を支えるための補助機能とする。
- 感想・理由・満足度は、査定のための点数付けではなく、振り返りと学習の材料として扱う。
- 残高不一致は、まず記録漏れに気づく機会として扱う。自動的な強い罰ではなく、透明で取り戻せる軽い影響に留める。
- 兄弟・他人との比較はしない。比較する場合は過去の本人との比較だけにする。
- お金の判断は、金額だけでなく目的・計画・振り返り・記録習慣を合わせて見る。
- 収集した情報は、必ず子ども本人の振り返り、親との会話、次回査定の説明可能な判断材料のいずれかに活用する。
- 便利さよりも、子どもが自分で気づき、考え、次の使い方を改善できることを優先する。

## 機能概要

- AI（claude CLI）が会話を主導し、お小遣い査定（固定 / 臨時）を提案する（親承認で支給）
- お小遣い帳（支出記録）を保存する
- 財布残高（ウォレット）を管理する
- 支出理由・満足度・記録漏れから、親子会話カードと子どもの小さなチャレンジを作る
- 親が子ども別のAIフォロー方針、会話カード反応、成長行動プランを管理できる
- 毎月リマインド（支給前通知）と残高監査を行う
- 親向けダッシュボード・低残高アラート・月次サマリー・傾向分析・目標貯金に対応
- ブラウザから閲覧できる Webダッシュボードを搭載

## 必要環境

- Python 3.11+
- Discord Bot Token（Discord Developer Portal で作成）
- **claude CLI**（会話の主役。ローカルにインストールし、ログイン済みであること）

会話は claude CLI が主導します。金額を動かす処理だけを Python の MCP wallet tool（`app/mcp_wallet.py`）が担当します。
**Anthropic の API キーは使いません。** Bot を動かすマシンの claude CLI をそのまま呼び出すため、導入した人自身の Claude アカウントで動きます。

## セットアップ（最短手順）

```bash
# 1. claude CLI を用意（インストールしてログイン済みにしておく）
claude --version

# 2. 依存インストール
git clone <このリポジトリ>
cd compass-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. 環境変数（DISCORD_BOT_TOKEN を設定）
cp .env.example .env

# 4. MCP wallet 設定のパスを自分の環境へ書き換える
#    config/wallet_mcp.json の command / cwd

# 5. 設定ファイルを作る
cp settings/setting.example.json settings/setting.json
cp settings/users/parents/parent.example.json settings/users/parents/<親の名前>.json

# 6. 起動（Webダッシュボードも同一プロセスで起動・既定 port 8765）
python3 -m app.bot
```

各手順の詳細、ユーザーの追加方法、設定項目の一覧、Discord コマンド全26種、Web の公開設定は
**[使い方ガイド](#使い方ガイド詳細版)** を参照してください。

> **⚠️ 会話履歴の保存先に注意**
> 子どもとの会話履歴の実体は、このリポジトリの中ではなく **`~/.claude/projects/` 配下** にあります。
> `data/` だけをバックアップしても会話履歴は復元できません。詳細は使い方ガイドの「会話履歴の保存先」を参照してください。

## 使い方ガイド（詳細版）

**ドキュメントの正本は Web の使い方ガイドです。** Bot を起動した状態で、ブラウザから開けます。

```
http://<ホスト>:8765/compass-bot/readme
```

公開設定をしている場合は `https://<あなたのドメイン>/compass-bot/readme` です。
Web ダッシュボードのヘッダー「📖 使い方」からも開けます。ログイン不要で閲覧できます。

### ダッシュボードの入り方（2026/08/10 に変更）

**パスワードは使いません。** 自分専用の URL を開くだけで入れます。

1. Discord で `URL再発行` と送る
   - 子は**自分のチャンネル**で、親は**親チャンネル**で送る
   - 親には DM で届きます（DM が使えない場合は親チャンネルへ）
2. 届いた URL を開く。ブックマークすれば次からはそれだけで入れます

URL は1人1つで、再発行すると古いものは無効になります。
URL をなくした・人に見られたときは、もう一度 `URL再発行` と送ってください。

**なぜパスワードをやめたか**: 申請 → 親の承認 → 仮パスワード → 本パスワード設定 →
7日ごとの再ログイン、という手順が子どもには重すぎて使われないためです。
URL 方式なら覚えることがゼロで、期限もありません。

### 子ども用ダッシュボード

子は `/compass-bot/child` で自分の画面を見られます（**閲覧専用**）。

| 場所 | 内容 |
|---|---|
| 左 | カレンダー。日ごとに「はいった額 / つかった額」が出る |
| 右 | 目標のバー。貯金と立て替え返済を同じ形で表示。下に「過去の自分」との比較 |
| 下 | シミュレータ。目標額と積む額から回数・達成月を計算し、チャットへ貼れる文面を作る |

**他の子の情報は一切出しません**。金額を動かす操作もここにはありません。

## ディレクトリ構成

- `app/`: Bot 本体。Discord 連携、AI 会話、残高・支出・目標の管理、定期通知、Web サーバーなど。
- `templates/`: Web ダッシュボードと使い方ガイドの HTML テンプレート。
- `config/wallet_mcp.json`: AI が財布操作ツールを呼ぶための設定（実環境のパスに書き換えて使う）。
- `settings/`: 設定ファイル。実運用の設定・ユーザー情報は各自が作成します（テンプレートの `*.example.json` のみ同梱）。
- `scripts/`: 常駐用の systemd unit サンプルなど。
- `tests/`: 自動テスト。
- `data/logs/`: 実行時に生成されるログ（残高台帳・お小遣い帳・イベント等）。リポジトリには含まれません。

## 注意点

- 個人情報を含む実設定（`settings/setting.json`, `settings/users/*.json`, `settings/users/parents/*.json`）は `.gitignore` で除外し、テンプレート（`*.example.json`）のみ共有します。
- コード変更を本番へ反映するには、コミットだけでなく `sudo systemctl restart compass.service` が必要です。
- 同じ Discord ユーザーIDを親と子の両方に登録しないでください（本人判定が壊れます）。
