Compass Bot — 使い方ガイド

ドキュメントの正本は、Bot が配信する Web の使い方ガイドです。

Bot を起動した状態で、下のリンクから開いてください。

使い方ガイドを開く

リンクが開けない場合は、Bot を動かしているホストの http://<ホスト>:8765/compass-bot/readme を直接開いてください。
公開設定をしている場合は https://<あなたのドメイン>/compass-bot/readme です。

ガイドが開けないとき

  • Bot が起動しているか確認する（systemctl status compass.service）
  • ローカルで試すときは http://localhost:8765/compass-bot/readme
  • 導入手順だけなら、リポジトリの README.md にも要点があります

このファイルは入口のリンク集です。内容の正本は Web ガイド側にあります（二重管理を避けるため、 ここに手順は書きません）。
